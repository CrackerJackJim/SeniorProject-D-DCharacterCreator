# SeniorProject-D-DCharacterCreator

How to get to the project:
Go to the "Server side" folder located in the "MySQL" folder, it should look something like "Z:\DnD_Final_Project\MySQL\Server_side"

What you NEED to do before running the server:
You need to make a local account with the password "Ilovemygpu!1" or you will need to find the files "db.py" and "core.py" and change them to be what ever your login is.

How to start the server:
Open CMD (Command Prompt), go to the directory up to the "Server_side" folder then run "uvicorn main:app --reload". This is what I run when I run the server "z: && cd Z:\DnD_Final_Project\DnD_Project && uvicorn Server_side.main:app --reload"
